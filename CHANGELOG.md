# Changelog

## 2.0.0 — 2026-09-23

- Add nominal flock-centroid interception and changing aircraft altitude for climb and final approach.
- Add sound propagation, Doppler, hearing reference criteria and light irradiance/photon calculations.
- Separate measurement-only sensory signals from the uncalibrated response hypothesis.
- Add a robotic-falcon scenario, selected escape directions, CV forecasts and within-simulation RMSE.
- Export per-bird CSV and event/centroid JSON traces.
- Document references, assumptions and model limitations in the interface and README.
- Include 14 model/sensor tests, a standalone HTML build, English/Vietnamese documentation and a demo image.

This is the first version prepared for this repository. Version 1 was an earlier local prototype; its history is not represented as historical Git commits.
